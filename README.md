# GoogleViews

Στατικό site (HTML/CSS/JS, χωρίς framework) για κάρτες NFC κριτικών Google.
Σχεδιαστική γλώσσα: Google Gemini / Material 3 Expressive. Όλα τα κείμενα
είναι στα ελληνικά.

---

## Πώς το τρέχεις τοπικά

Άνοιξε απλώς το `index.html` με διπλό κλικ. Δεν χρειάζεται server.

Αν προτιμάς server (για να δουλεύουν σωστά τα απόλυτα paths):

```bash
npx serve .
```

## Πώς ανεβαίνει online

Είναι καθαρά στατικό. Σύρε τον φάκελο στο Netlify Drop, ή σύνδεσέ τον με
Vercel / Cloudflare Pages / GitHub Pages. Δεν χρειάζεται build step στον server.

---

## Δομή

```
index.html            Αρχική
nfc.html              Τι είναι το NFC (ο οδηγός)
pos-leitourgei.html   Πώς λειτουργεί
proionta.html         Προϊόντα
times.html            Τιμές

Η φόρμα επικοινωνίας δεν έχει δική της σελίδα — ζει στο τέλος της αρχικής,
στην ενότητα με id `epikoinonia`. Όλα τα κουμπιά «Ζήτησε προσφορά» δείχνουν
στο `index.html#epikoinonia`.

_content/*.html       ΤΟ ΠΕΡΙΕΧΟΜΕΝΟ κάθε σελίδας (μόνο το <main>)
build.py              Τυλίγει το _content σε <head> + nav + footer.
                      Περιέχει και το σχέδιο της κάρτας (REVIEW_CARD /
                      REVIEW_STAND / REVIEW_STICKER) — μπαίνει όπου μια
                      σελίδα γράφει <!--REVIEW-CARD--> κ.λπ.

assets/css/style.css       Design tokens, χρώματα, τυπογραφία, aurora
assets/css/components.css  Κουμπιά, κάρτες, nav, FAQ, φόρμες, footer
assets/css/mockups.css     Η κάρτα (.rcard), κινητό, σταντ, προφίλ Google
assets/css/pages.css       Διατάξεις ανά σελίδα/ενότητα
assets/js/main.js          Μενού, reveals, FAQ, φόρμα, tilt
assets/img/                Λογότυπο, εικονίδια, φωτογραφίες
```

### Επεξεργασία περιεχομένου

Άλλαξε το `_content/<σελίδα>.html` και μετά τρέξε:

```bash
python build.py
```

Αυτό ξαναγράφει τα `.html` στη ρίζα. **Μην** επεξεργάζεσαι τα αρχεία της ρίζας
απευθείας — θα χαθούν στο επόμενο build.

Το nav, το footer, τα meta tags και τα titles ζουν όλα μέσα στο `build.py`.

## Τι ΠΡΕΠΕΙ να αλλάξεις πριν βγει online

| Τι | Πού |
|---|---|
| **Email** (`info@googleviews.gr`) | `build.py` → `EMAIL`, και η φόρμα στο `_content/index.html` |
| **Τηλέφωνο** (`+30 690 000 0000`) | `build.py` → `PHONE_HREF`, `PHONE_TEXT` |
| **Domain** (`https://googleviews.gr`) | `build.py` → `SITE`, και `robots.txt`, `sitemap.xml` |
| **Τιμές** (39 / 89 / 169 € και τα πρόσθετα) | `_content/times.html` — είναι ενδεικτικές |
| **Στατιστικά** (98%, 87%, Top 3) | `_content/index.html` — πηγές BrightLocal & Whitespark· επιβεβαίωσέ τα |
| **Προδιαγραφές προϊόντων** (διαστάσεις, υλικά) | `_content/proionta.html` — βάλε ό,τι πραγματικά πουλάς |

Μετά από κάθε αλλαγή: `python build.py`.

### Η φόρμα επικοινωνίας

Αυτή τη στιγμή δεν υπάρχει backend. Η φόρμα κάνει έλεγχο των πεδίων και μετά
ανοίγει το πρόγραμμα email του χρήστη με το μήνυμα προσυμπληρωμένο.

Για κανονική υποβολή, βάλε μια υπηρεσία όπως Formspree / Netlify Forms /
Web3Forms και άλλαξε τη συνάρτηση `initForm()` στο `assets/js/main.js`.
Η φόρμα βρίσκεται στο `_content/index.html`.

## Σχεδιαστικές σημειώσεις

Τα χρώματα, οι καμπύλες κίνησης και οι ακτίνες γωνιών είναι οι πραγματικές
τιμές του Gemini / Material 3, όχι προσεγγίσεις:

- **Gemini gradient** — `linear-gradient(72.83deg,#4285F4 11.63%,#9B72CB 40.43%,#D96570 68.07%)`
- **Φόντο** — στο φωτεινό θέμα η σελίδα είναι **λευκή από άκρη σε άκρη**. Οι
  εναλλασσόμενες ενότητες (`.section--sunken`) δεν έχουν γκρι μπάντα· παίρνουν
  ένα ελάχιστο χρωματικό «φως» (`--section-alt`) που σβήνει στο μηδέν και στις
  δύο άκρες, ώστε να μην υπάρχει ορατή ραφή. Το βάθος βγαίνει από τις κάρτες
  (`--shadow-card`), όχι από πιο σκούρο φόντο.
- **Επιφάνειες** — ο τονικός καταρράκτης του Gemini (`#FFFFFF → #F8FAFD → #F0F4F9 → #E9EEF6 → #DDE3EA`) μένει για ένθετα στοιχεία (πεδία φόρμας, chips, στάδια προϊόντων)· σκούρο θέμα `#131314 → #1E1F20 → #282A2C`
- **Κίνηση** — M3 easing (`cubic-bezier(.2,0,0,1)`) και Expressive springs (`cubic-bezier(.38,1.21,.22,1)`)
- **Σκιές** — διακριτικές, αλλά υπαρκτές: πάνω σε λευκό φόντο οι κάρτες χρειάζονται δικό τους «σήκωμα»
- **Το aurora** στο hero είναι η τεχνική του Gemini: μια τεράστια λωρίδα ουράνιου
  τόξου γυρισμένη στις −36°, που κυλάει συνεχώς και φαίνεται μόνο μέσα από
  θολωμένα «σύννεφα». Στα κινητά η κίνηση σταματά για λόγους απόδοσης.
- **Γραμματοσειρά** — Inter (πλήρης ελληνική υποστήριξη). Το Google Sans δεν
  διατίθεται με άδεια, γι' αυτό μπαίνει πρώτο στο stack αλλά με το Inter από πίσω.

Το site είναι **μόνο σε φωτεινό θέμα**. Δεν υπάρχει διακόπτης σκούρου θέματος
και δεν υπάρχουν κανόνες `[data-theme="dark"]` στο CSS.

## Νομικά — διάβασέ το

Το όνομα **GoogleViews** περιέχει το σήμα «Google». Οι οδηγίες χρήσης σημάτων
της Google **δεν επιτρέπουν** τη χρήση της λέξης «Google» στο όνομα εταιρείας,
προϊόντος ή domain τρίτων. Υπάρχει πραγματικός κίνδυνος αιτήματος αφαίρεσης ή
απώλειας του domain αργότερα.

Στο footer κάθε σελίδας υπάρχει ήδη δήλωση αποποίησης, που βοηθά αλλά δεν λύνει
το θέμα του ίδιου του ονόματος. Αξίζει να το σκεφτείς πριν τυπώσεις κάρτες και
πριν χτίσεις πελατολόγιο πάνω στο brand.

Το ίδιο ισχύει και για **το λογότυπο «G»** που εμφανίζεται πάνω στην κάρτα
(`REVIEW_CARD` στο `build.py`). Είναι σήμα κατατεθέν της Google. Όλα τα προϊόντα
αυτής της κατηγορίας το χρησιμοποιούν, αλλά τυπικά χρειάζεται άδεια. Αν θέλεις
να το αποφύγεις, αντικατέστησε το `<svg>` μέσα στο `.rcard__g` με το δικό σου
λογότυπο (`assets/img/logo.webp`) — η υπόλοιπη κάρτα δεν αλλάζει.

Επίσης, το site είναι γραμμένο ώστε να **συμμορφώνεται** με τις πολιτικές του
Google για τις κριτικές: καμία υπόσχεση για φιλτράρισμα αρνητικών κριτικών, καμία
προτροπή για ανταλλάγματα. Μην το αλλάξεις αυτό — το review gating μπορεί να
κοστίσει το προφίλ των πελατών σου.
